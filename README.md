# Демо-лендинг житлового забудовника

Односторінковий сайт. Назву забудовника, назви кварталів та адреси приховано
за угодою про нерозголошення — замість них нейтральні позначення
(«Квартал I / II / III», локації описані характером, а не адресою).
Ціни, дати й показники умовні.

## Як відкрити

```bash
python3 -m http.server 8777
```

Далі `http://localhost:8777`. Сторінка на ES-модулях, тому потрібен саме
сервер, а не подвійний клік. Публікація — залити папку на Netlify, Vercel,
GitHub Pages чи nginx. Збірки немає, залежностей у репозиторії немає.

## Файли

```
index.html              одна сторінка, уся розмітка
assets/css/style.css    токени та стилі
assets/js/data.js       ВСІ дані демо — правити тут
assets/js/draw.js       генератори креслень (SVG)
assets/js/main.js       поведінка та рух
assets/img/             фотографії
```

## Фотографії

Тимчасові знімки з Unsplash (Unsplash License: вільне комерційне використання,
атрибуція не обовʼязкова). Вони показують рівень, а не реальні обʼєкти.

Щоб підставити матеріали замовника — покладіть файли в `assets/img/` з тими
самими іменами, решта підхопиться сама:

| Файл | Де | Пропорція | Примітка |
|---|---|---|---|
| `hero.webp` | перший екран | 16:10 | потрібен темний кадр — по ньому йде білий шрифт |
| `build.webp` | блок «Хід будівництва» | 16:11 | |
| `quarter-1…3.webp` | картки кварталів і колаж | 4:5 | |
| `unit-1…8.webp` | картки квартир | 4:3 | інтерʼєри, йдуть по колу |

Список шляхів — у `PHOTOS` та `UNIT_PHOTOS` наприкінці `data.js`.

## Що ще міняти під замовника

- `BRAND` — місто, телефон, пошта;
- `COMPLEXES` — квартали, їхні `works` (роботи з датами та `done` у відсотках)
  і `FLOORS` (монтаж перекриттів);
- `UNITS` — квартири у продажу;
- `LAYOUTS` — планування: кімнати в дециметрах, вікна за сторонами світу;
- `DEAL`, `STATS`, `FAQ` — етапи, показники, питання;
- `TIMELINE.today` — дата, на яку показані факти.

Відсоток готовності та кількість змонтованих поверхів **не задані руками** —
вони рахуються з календарного плану на дату `TIMELINE.today`.

Тексти секцій — в `index.html`. Плашку замість назви забудовника задає клас
`.redact` у `style.css`; коли зʼявиться дозвіл на розкриття — заміняйте її
на звичайний текстовий логотип.

## Інсоляція

Розділ «Куди світить сонце» рахує реально: напрям світла береться з години,
підсвічуються лише вікна, повернуті до сонця, а промінь обрізається кімнатою,
у яку заходить. Північні кімнати не отримують прямого світла ніколи — план
показує це чесно.

## Технічне

- GSAP і ScrollTrigger з CDN; якщо не завантажаться, сторінка лишається цілою.
- `prefers-reduced-motion` вимикає рух.
- Вступна анімація має запобіжник: у фоновій вкладці браузер душить
  `requestAnimationFrame`, тому через 2.6 с сцени доводяться до кінця вручну.
- Фотографії — WebP, `loading="lazy"` нижче першого екрана.
- Перевірено на 390 / 900 / 1100 / 1440 px.
- Форма запису демонстраційна, дані нікуди не надсилаються.
